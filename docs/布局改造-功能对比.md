# 布局改造 · 功能对比（现网 vs 实验室）

> **日期**：2026-09-15  
> **用途**：按 [布局改造方案.md](./布局改造方案.md) 分期接到生产时的验收清单。  
> **口径**：以**现网已实现**为准。实验室 `/#/ui-lab/deck` 是 mock 视觉稿，点得动不等于已接线。  
> **进度**：第 1–3 刀已接到生产。  
> **标记**：现网 = 生产已有；实验室 = 整合稿现状；验收 = 该刀完成后必须仍在（或首次接到生产）。

勾选在实现时改本文，或在 MR 里对照打勾。未列入「实验室有」而现网有的，**不得因 Deck 没画就删**。

---

## 怎么用

1. 第 N 刀只验收对应章节；其它章可以仍是旧 UI，但功能不能坏。
2. 实验室列「示意」= 有按钮或文案，**没有**调现网 API。
3. 实验室列「缺失」= 整合稿没入口。
4. 写操作都要保留 dry-run 确认框（现网 `ConfirmDialog` / 聊天 `ConfirmBar`）。

## 1. 工作台（第 2 刀）

实验室缺口最多的一页。现网主路径是打开本地仓和克隆，整合稿里「打开」按钮**没有** `@click`。

| # | 功能点 | 现网 | 实验室 | 验收 |
|---|--------|------|--------|------|
| 1.1 | 输入本地路径打开仓库 | `openRepo`；回车/按钮；成功切当前仓并刷新一览 | 有输入框，打开**未接线** | 空路径提示；失败报错；成功入列表并选中 |
| 1.2 | 克隆到本地 | `CloneDialog`：地址 + 绝对路径；后台 Job；禁止 URL 带 token；完成后入一览 | 弹层示意，提交只跳任务页 | 真 `startClone`；进 `/jobs`；成功出现在一览 |
| 1.3 | 无仓空态 | 「还没有打开仓库…」+ 打开/克隆 | 英雄卡空态 | 打开/克隆可用 |
| 1.4 | 筛空 | 「没有符合筛选的仓库」 | 弱 | 要有 |
| 1.5 | 卡片：名、路径、分支、ahead/behind、更改数 | 有 | 部分 | 对齐现网 |
| 1.6 | 卡片：冲突数、operation（merge/rebase）、合并草稿数 | 有 | 部分/无草稿 | 对齐现网 |
| 1.7 | 12 周按日热力、上次打开时间 | 有 | 有热力 | 有；`last_opened_at` 只展示，MCP 默认仓逻辑不变 |
| 1.8 | 单击选当前仓（其余可压暗） | 有 | 有 | 有 |
| 1.9 | 双击 /「进入」→ 状态（activate） | 有 | 英雄卡示意 | 真跳转 `/status` |
| 1.10 | 「合并」→ 合并页（activate） | 有 | 英雄卡示意 | 真跳转 `/merge` |
| 1.11 | 从列表移除（确认，不删磁盘） | 有 | 文案有，**卡片无按钮** | **必须有** |

| 1.15 | 天气数字条与仓库网格分开 | 芯片在列表头 | 已拆开 | 禁止再把仓卡挤进数字格 |

| 1.17 | 刷新一览（repos + overview） | 有 | **缺失** | 有 |
| 1.18 | 拖拽排序写入 `pin_order`（按当前筛选列表重排） | 有 | **缺失** | **必须有** |

天气映射（验收时同一套 `attentionOf`）：

| 天气 | 现网芯片 | 判定 |
|------|----------|------|
| 雷雨 | 卡住 | 不可用，或 operation≠none，或 conflictCount>0 |
| 薄雾 | 有更改 | dirtyCount>0 |
| 刮风 | 未同步 | ahead+behind>0 或 tempMergeBranchCount>0 |
| 晴天 | （新增） | 其余 |
