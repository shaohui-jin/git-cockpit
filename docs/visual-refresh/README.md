# Git Cockpit · 全站视觉改版原型

静态高保真 HTML 原型，覆盖 7 个路由页 + 1 个评审枢纽，签名主色 teal / 极地白双套实时切换。

**本目录只新建文件，未改动 `packages/` 与 `docs/` 下任何既有文件。**

## 怎么查看

直接双击 `index.html` 用浏览器打开即可，无需构建、无需服务、不连后端。

`index.html` 是评审入口，包含设计系统速览、标志性组件画廊、8 页入口卡片、Anti-Slop 自查与已定/待定清单。

## 双主色切换

- **左下角浮动切换器**：两个色块，点击即切换，全站生效。
- **`index.html` 顶部显眼分段控件**：同样的切换，带当前方案高亮与"当前：teal 青绿 / 当前：极地白"状态徽标。
- 选择写入 `localStorage`（键 `gc-accent`），跨页保持；下次打开自动恢复。
- 实现：`:root` 为 teal 默认；`html[data-accent="white"]` 仅覆盖主色相关变量、热力图 5 档与冲突 OURS 色。表面、边框、文字、语义色两套共用。

## 实现说明与取舍点

以下是需要主理人与用户知情的判断，均已在实现中隔离或标注：

1. **冲突选边行为 3 列**（行号 + OURS 栏 + THEIRS 栏），而非任务书字面的"行号｜OURS chip｜THEIRS chip｜内容"四列。chip 与代码内容同栏，符合 diff 双栏阅读习惯，也避免内容列归属歧义。

2. **脉冲条在极地白下改用冷色阶**（`--gc-signal-bar` #a3b0bf、扫描段 #eef4f9）。任务书给的 #1a9e92 / #6ff0e0 属 teal 系固定值，在极白主色下会与整体脱节、且与扫描段对比不足。已用变量隔离，teal 下仍严格为规格值。

3. **极地白下冲突选边 OURS 改用绿结构色**（`--gc-ours-bg/border/text` 在 `html[data-accent='white']` 下覆盖为 `rgba(86,217,122,.12)` / `rgba(86,217,122,.35)` / `#56d97a`）。依据是任务书第七条 4 的明文要求（"极白主色下 = 绿结构色同构"），目的是与 THEIRS 紫保持足够区分。

   > 以上第 2、3 条是**仅有的两处**对令牌字面值的主动调整，均以变量隔离，teal 下严格保持规格原值。

4. **status 页聊天球与面板并排**（球在面板左侧 12px）。任务书要求同时演示 confirm 态悬浮球与打开的面板，但真实产品中二者互斥；并排是为了让评审一屏内看到两个组件。

5. **聊天球保留 52px 正圆（已豁免圆角纪律）**。理由：这是产品现有的可拖拽悬浮球标志语言，属于既有签名组件，不是装饰性大圆角；改成方圆会破坏拖拽球的识别度。同理 dock 徽标、状态点等圆形元素均为功能形状。

6. **热力图用少量内联 JS 生成**（12 周 × 7 天，固定散列保证每次渲染一致），避免 84 个手写节点。工作日活跃度高于周末，符合真实提交分布。

7. **顶栏只放符号 + 3 个连接 tag**，未加页面名。遵守"顶栏只放符号、`Git Cockpit` 字标仅 index 出现一次"。连接 tag 的文案用「前端 / 后端 / 桌面」，对应三个真实进程。

8. **图标通过 `icons.js` 注入内联 SVG**。最终 DOM 中仍是同文档内联 SVG，无第三方图标库、无 emoji；好处是 8 页图标完全一致、可统一改笔触。若需要"HTML 源码里直接可见 SVG"，可把 `icons.js` 的字典逐条展开到各页。

9. **矩阵单元格用 check / close / minus 三个 SVG 图标**而非 ✓ ✕ — 字符，避免不同平台字体差异；同时保留语义弱底，形成符号 + 颜色双编码。jobs 页日志尾行的 ✓/✕ 同样已换成图标。
